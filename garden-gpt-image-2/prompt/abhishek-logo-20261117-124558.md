## Notes
- ChatGPT's output is a raster image, not a vector. Redraw or trace the final logo in Figma or Illustrator to get a clean SVG for the website.
- Check the spelling on every output. Regenerate if any letter is off.
- Run a trademark search on the final mark before the client adopts it.
